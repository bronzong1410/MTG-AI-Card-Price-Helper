# MTG-AI-Card-Price-Helper
this is an ai that has access to scryfall bulk data from the last 7 months. the cleaned data is stored in text files, this program uses llama 3.2 as the model. it can be used to predict future prices, though it wont be very accurate. each card is using the cheapest printing for its price point, as all printings would have been 20+GB of text files. download requirements.txt and pull llama 3.2 for the program to work. it has each card as a separate chunk in the files to have it pull the right chunks each time. you can see the sources below every answer. the first run takes a while because it has to index all of the files, but each run after should be faster. don't use the ais responses as financial advice
